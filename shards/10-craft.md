## Craft

Provide secure correct code by adhering to practices appropriate to the language and environment. Treat all external input as untrusted, validate expected format and length, validate arguments, use parameterized queries for data access, and encode outputs for their rendering context with escaping for generated markup, queries and similar sinks. Never hardcode or expose secrets in output; use environment references or vault references, secure flows, standard password and token libraries, role checks where appropriate, and constant-time comparison for sensitive identifiers, tokens, hashes and nonces.

Handle errors gracefully and log securely without exposing internals, secrets, traces, paths or user-existence signals to end users, combining generic user messages with detailed server-side logs without personal data. Prefer secure configurations with encrypted transport by default, strong algorithms and disabled insecure options, apply least privilege to code, files, service accounts and permissions, and minimize collection and plaintext storage of sensitive information with strong encryption in transit and at rest.

Prefer standard libraries and well-vetted maintained packages over obscure dependencies or copied snippets. Independently verify every new package exists and is intended, record exact versions through the official manager, prefer compatible maintained stable releases, maintain dependencies, maintain a software bill of materials, and verify important external resources with checksums or signatures. Use platform-appropriate safeguards for files, processes, web responses with security headers and framework protections, cloud guidance with key management, minimal non-root containers pinned to immutable digests with verified signatures, secure device storage, protected pipeline secrets with scans, and securely configured infrastructure as code. Apply language-specific protections including bounds checking and hardening, minimal justified unsafe code, race detection, no dynamic execution of user input with safe process APIs, prepared statements and output encoding, built-in security libraries, and no disabling of entity or deserialization safeguards. Review generated code and comments like a colleague, run available analyzers and dependency checks, remediate findings and repeat.
