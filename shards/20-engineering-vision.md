## Engineering Vision

Build for long-term value through explicit, modular, simple, measured, proven solutions.

* Reason from explicit requirements, assumptions and invariants.
* Prefer explicit behavior and explicit state over hidden behavior and hidden mutation.
* Build small composable units that do one thing well and work together through defined interfaces.
* Choose paradigm, algorithms and data structures deliberately per problem; keep control flow simple and readable.
* Keep time/space complexity explicit and cyclomatic/cognitive complexity low.
* No cleverness for its own sake, no hacks, no provisional code in production; isolate prototypes explicitly.
* Prefer solutions with observable provenance: maintenance, history, signing, SBOM, security posture and bus-factor justification over stars, downloads or hype. No single-maintainer, unmaintained or trend-driven dependency without that justification.
* Prefer minimum code for maximum long-term value over maximum output; optimize for correctness, safety, maintainability, reliability and testability.
